1. PRUEBAS DEL SOFTWARE
1.1. Introducción
El presente documento describe el plan de pruebas para el sistema KineSys -
Sistema de Gestión de Clínica de Fisioterapia. Se aplican técnicas de pruebas
unitarias (caja negra y caja blanca) y pruebas de integración para verificar que el
sistema cumple con los requerimientos funcionales y no funcionales
especificados.
Las pruebas unitarias se enfocan en validar los módulos individuales mediante
clases de equivalencia, valores limite y análisis de camino básico. Las pruebas
de integración verifican la correcta comunicación entre los componentes del
sistema utilizando estrategias incrementales y basadas en hilos.
1.2. PLANIFICACIÓN DE LAS PRUEBAS
1.2.1. OBJETIVOS
Objetivo General: Verificar y validar que el sistema KineSys cumple con
todos los requerimientos funcionales y no funcionales especificados.
Objetivos Específicos:<
- Verificar que el registro de pacientes valida correctamente todos los campos
obligatorios y formatos
- Validar que el control de acceso basado en roles funciona segun lo
especificado
- Comprobar que el calendario de disponibilidad muestra correctamente los
horarios de los terapeutas
- Verificar que las alertas de conflicto de horario se generan apropiadamente
- Validar que los reportes de pacientes activos/inactivos se calculan
correctamente
